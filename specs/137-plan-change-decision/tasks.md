## Dependencies and order

- Phase 1 → 2 → (3, 4) → 5; phases 3 and 4 share `keep-plan-form.tsx` (built in T017, reused in T024), so do 3 before 4.
- Within a phase, tasks marked [P] touch different files and can run together; everything else follows the order written.
- MVP = phases 1 and 2 (the API decides and posts), but the story is only done with all five phases and the final verification.
