## Implementation strategy

MVP is US1 end to end (invite by email and copy the link): T002–T010, the create path of #28, and the dialog of #29. It does not ship alone: the story's criteria also need the list (US2) and revoke (US3), so the pull request merges only when all three tasks are done. Each task ends with green gates and its own commit, so review can follow the commits one by one.
