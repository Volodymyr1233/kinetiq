# Contract: messaging API

The binding contract is the OpenAPI document generated by the backend; this file lists what the code must produce so the screens and tests agree. All paths are under `/api/v1`. Every endpoint requires a sign-in as a client or a trainer (no public endpoint). The two writes need the CSRF header. `{clientId}` is the id of the client of the conversation: a client uses their own id, a trainer the id of one of their clients.

Errors are problem details with a `code` (FR-012). The screens translate by `code` and show no server text.

## `GET /conversations`

The signed-in person's conversations. For a trainer, one row per linked client; for a client, one row (their trainer's).

**200**

```json
{
  "conversations": [
    {
      "clientId": "uuid",
      "name": "name of the other person",
      "goal": "BUILD_MUSCLE | ... | null",
      "currentWeek": 3,
      "planWeeks": 8,
      "unreadCount": 2,
      "lastMessage": { "preview": "text, at most 140 characters", "sentByMe": false, "sentAt": "2026-11-02T09:12:00Z" }
    }
  ]
}
```

`lastMessage` is `null` for a conversation without messages. Order: newest last message first, then those without messages by name (case-insensitive), then id. `goal`, `currentWeek` and `planWeeks` are for a trainer's rows and are left out of a client's own row, whose plan can still be a draft; the two week fields are left out until the plan is published, and `currentWeek` is above `planWeeks` once it has finished.

## `GET /conversations/{clientId}/messages?before={messageId}`

One page of the conversation. Without `before`, the newest 50 messages; with it, the 50 before that message. A pair that has no conversation yet gives an empty page.

**200**

```json
{
  "messages": [ { "id": "uuid", "text": "…", "mine": true, "sentAt": "2026-11-02T09:12:00Z" } ],
  "hasMore": false
}
```

`messages` run oldest to newest. `mine` says whether the signed-in person wrote it. The response has no sender id, no email and no read information (FR-008, FR-015).

**404** `conversation.not-found`: no such client, or the signed-in person is neither the client nor their trainer. **404** `message.not-found`: `before` is not a message of this conversation. **400** `request.invalid`: `clientId` or `before` is not an id.

## `POST /conversations/{clientId}/messages`

```json
{ "id": "uuid chosen by the sender", "text": "…" }
```

**201** the stored message (shape as in the page). Sending the same `id`, with the same text, again returns the same body and status.

| Status | `code` | When |
|---|---|---|
| 400 | `message.empty` | nothing is left after removing spaces and line breaks around the text |
| 400 | `message.too-long` | more than 2000 characters after trimming |
| 400 | `validation.failed` | `id` or `text` missing (`errors` lists the fields) |
| 404 | `conversation.not-found` | as above |
| 409 | `message.id-in-use` | the id exists with another text, sender or conversation |

## `PUT /conversations/{clientId}/read`

Marks the conversation read for the signed-in person (sets their last-read time to now; never earlier than before). No body.

**204**. Also 204 for a pair without a conversation (nothing to mark). **404** `conversation.not-found` as above. Idempotent.

## `GET /conversations/unread-count`

**200** `{ "count": 3 }`: the number of messages from the other person after the signed-in person's last-read time, over all their conversations (FR-006).

## Not in the contract

No endpoint to create, edit or delete a conversation or a message, to search messages, or to read whether a message was read. The trainer's search runs in the browser over `GET /conversations`.

## Frontend routes

| Route | Page | Area |
|---|---|---|
| `/app/messages` | Client conversation | client, tab "Messages" |
| `/trainer/messages` | Conversation list, nothing selected | trainer |
| `/trainer/messages/:clientId` | List with the conversation open | trainer |

An id in `/trainer/messages/:clientId` that is not one of the trainer's clients (including text that is no id) shows the not-found state of the conversation area; the list stays.
