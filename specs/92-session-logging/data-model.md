# Data Model: Client logs sets

Migration `V17__create_session_logs.sql` (renumber to the next free number if taken). Named constraints, as in earlier migrations.

## `session_logs`

| Column | Type | Rule |
|---|---|---|
| `id` | uuid | primary key, created by the application |
| `client_id` | uuid | not null, foreign key to `accounts` |
| `log_date` | date | not null; the client's local date at the start |
| `session_name` | varchar(60) | not null, not blank; copy of the planned session's name |
| `started_at` | timestamptz | not null |
| `finished_at` | timestamptz | null; set by story #98, never by this story |
| `created_at`, `updated_at`, `version` | | as the other entities |

Unique: `uq_session_logs_client_date (client_id, log_date)`. Check: `finished_at is null or finished_at >= started_at`.

## `session_log_entries` (copy of the plan's entries)

| Column | Type | Rule |
|---|---|---|
| `session_log_id` | uuid | foreign key to `session_logs`, part of the key |
| `position` | integer | part of the key, `>= 0`; order in the session |
| `exercise_id` | uuid | not null, foreign key to `exercises` |
| `sets` | integer | `between 1 and 20` |
| `amount` | integer | `between 1 and 3600` (repetitions or seconds, as the exercise measures) |
| `load_kg` | numeric(4,1) | null, `> 0` |
| `rpe` | integer | `between 5 and 10` |
| `rest_seconds` | integer | `between 0 and 600` |

## `set_logs`

| Column | Type | Rule |
|---|---|---|
| `id` | uuid | primary key, **generated by the client** |
| `session_log_id` | uuid | not null |
| `entry_position` | integer | not null; with `session_log_id`, a foreign key to `session_log_entries` |
| `set_number` | integer | `>= 1` (the check that it is within the entry's sets is in the domain) |
| `load_kg` | numeric(4,1) | null, `> 0` |
| `amount` | integer | `between 1 and 3600` |
| `rpe` | integer | `between 5 and 10` |
| `target_load_kg` | numeric(4,1) | null, `> 0`; copy of the entry's target when logged |
| `target_amount` | integer | not null, `between 1 and 3600` |
| `target_rpe` | integer | not null, `between 5 and 10` |
| `logged_at` | timestamptz | not null |
| `created_at`, `updated_at`, `version` | | as the other entities |

Unique: `uq_set_logs_place (session_log_id, entry_position, set_number)`. Index on `session_log_id`.

## Rules

- A client has at most one session log a date; starting again returns it.
- A set log's id never moves to another place or session. A change replaces `load_kg`, `amount`, `rpe` and `logged_at`'s update time; the targets copy and the place stay.
- A plan save never touches these tables: they hold copies.
- Deleting an account is out of scope (story #167).

## State

```
(no log) --start--> started (finished_at null) --[#98]--> finished
set row: planned --log--> logged --change--> logged
```
